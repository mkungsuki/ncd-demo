# NCD Board — Demo (เฟสสาธิต)

หน้าสาธิตระบบคัดกรองผู้ป่วย NCD (เบาหวาน/ความดัน) — rule interpreter + บอร์ดสามบทบาท (พยาบาล/แพทย์/เภสัช)

**เปิดใช้:** https://mkungsuki.github.io/ncd-demo/

⚠️ ข้อกำกับ:
- **ตัวเลขเกณฑ์และคำแนะนำยาทั้งหมดเป็นตัวอย่างเพื่อสาธิตกลไก** — ไม่ใช่เกณฑ์ทางคลินิกจริง เกณฑ์จริงอยู่ระหว่างการพิจารณาของ med lead
- **ข้อมูลผู้ป่วยทั้งหมดแต่งขึ้น** (ชื่อสมมติ/HN สมมติ) ไม่มีข้อมูลผู้ป่วยจริง
- ห้ามใช้กับผู้ป่วยจริงไม่ว่ากรณีใด — เป็นเครื่องมือสื่อสารความคืบหน้าเท่านั้น

ไฟล์นี้ generate จากระบบ build ภายในโครงการ — แก้ที่ต้นทางแล้ว build ใหม่ ห้ามแก้ตรงนี้
